# Unit Testing with GenAI
This is my bachelor degree project.  
Artificial intelligence tools that have reached a point and become practical. My task is from the perspective of generating unit test cases, how are they, which one is better. 
The tools are an extension on the program or a program themselves.  
I will install the tools. I will evaluate how the generated unit tests are and how easy is it to work with the tools, how can prompts be given and what tasks can be done with the aim of generating unit tests.  
These units themselves have different levels of complexity.
I will choose three open source projects with different level of complexity in units. It should be mentioned that I am not stepping into Integration testing territories since it's not part of the project.  
Another perspective is how usable these tools are without the Internet. Basically switching to local models.  

These are the tools that I will work with:
- Github Copilot
- Continue.dev
- Tabnine
- Playwright
- Cursor AI
- Diffblue Cover
